logging モジュール

logging モジュールはロギング機能を提供します。

polyqa.logging.log(message)[ソース]

情報メッセージをログに記録します。

パラメータ:

message (str) -- ログに記録するメッセージ

polyqa.logging.debug_log(message)[ソース]

デバッグメッセージをログに記録します。

パラメータ:

message (str) -- ログに記録するデバッグメッセージ

polyqa.logging.warn_log(message)[ソース]

警告メッセージをログに記録します。

パラメータ:

message (str) -- ログに記録する警告メッセージ

polyqa.logging.error_log(message)[ソース]

エラーメッセージをログに記録します。

パラメータ:

message (str) -- ログに記録するエラーメッセージ
