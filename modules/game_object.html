find(name=None, pattern=None) → GameObject | None[ソース]

現在のゲームオブジェクト内で指定された名前またはパターンに一致する最初のゲームオブジェクトを検索します。

パラメータ:

  • name (str, optional) -- 検索するゲームオブジェクトの名前

  • pattern (str, optional) -- 検索するゲームオブジェクトの正規表現パターン

戻り値:

見つかったゲームオブジェクト。見つからない場合はNone。

戻り値の型:

int

例外:

ValueError -- nameもpatternも指定されていない場合
