polyqa パッケージ

polyqa モジュールはゲームテスト自動化のためのメイン機能を提供します。

polyqa.tap(v, **kwargs)[ソース]

画面上の指定された位置またはゲームオブジェクトをタップします。

使用例: tap(path: str, duration: float=0.0) path: ゲームオブジェクトのパス duration: タップの持続時間（秒）

tap(pos: tuple[float, float], duration: float=0.0) pos: 画面上の座標 duration: タップの持続時間（秒）

パラメータ:

  • v -- ゲームオブジェクトのパス文字列または座標タプル(x, y)

  • **kwargs -- 追加のパラメータ（duration など）

polyqa.swipe(v1, v2=None, **kwargs)[ソース]

画面上の2つの指定位置間またはゲームオブジェクト間でスワイプします。

使用例: swipe(path1: str, path2: str, duration: float=0.0) path1: 最初のゲームオブジェクトのパス path2: 2番目のゲームオブジェクトのパス duration: スワイプの持続時間（秒）

swipe(path1: str, pos2: tuple[float, float], duration: float=0.0) path1: 最初のゲームオブジェクトのパス pos2: 2番目の位置座標 duration: スワイプの持続時間（秒）

swipe(path1: str, vector: tuple[float, float], duration: float=0.0) path1: 最初のゲームオブジェクトのパス vector: スワイプの方向ベクトル duration: スワイプの持続時間（秒）

swipe(pos1: tuple[float, float], pos2: tuple[float, float], duration: float=0.0) pos1: 開始位置の座標 pos2: 終了位置の座標 duration: スワイプの持続時間（秒）

swipe(pos1: tuple[float, float], vector: tuple[float, float], duration: float=0.0) pos1: 開始位置の座標 vector: スワイプの方向ベクトル duration: スワイプの持続時間（秒）

パラメータ:

  • v1 -- 開始位置（ゲームオブジェクトのパスまたは座標タプル）

  • v2 -- 終了位置または方向ベクトル（デフォルト: None）

  • **kwargs -- 追加のパラメータ（duration など）

polyqa.input_text(path, text)[ソース]

指定されたゲームオブジェクトにテキストを入力します。

パラメータ:

  • path (str) -- テキストを入力するゲームオブジェクトのパス

  • text (str) -- 入力するテキスト

polyqa.sleep(seconds, check_interval=0.1)[ソース]

指定された秒数だけ実行を一時停止します。

パラメータ:

  • seconds (float) -- 停止する秒数

  • check_interval (float, optional) -- チェック間隔（秒）。デフォルトは0.1秒。

polyqa.go(name) → GameObject | None[ソース]

指定された名前のゲームオブジェクトを検索して返します。

パラメータ:

name (str) -- 検索するゲームオブジェクトの名前

戻り値:

見つかったゲームオブジェクト。見つからない場合はNone。

戻り値の型:

GameObject

polyqa.gos(name) → list[GameObject][ソース]

指定された名前のゲームオブジェクトをすべて検索してリストで返します。

パラメータ:

name (str) -- 検索するゲームオブジェクトの名前

戻り値:

見つかったゲームオブジェクトのリスト。見つからない場合は空のリスト。

戻り値の型:

list[GameObject]

polyqa.comment(text)[ソース]

指定されたテキストをエージェントのコメントとして表示します。

パラメータ:

text (str) -- 表示するコメントテキスト

polyqa.call_command(command_name)[ソース]

指定された名前のゲーム内コマンドを実行します。

パラメータ:

command_name (str) -- 実行するコマンドの名前

polyqa.ask(question: str, answer_type: str = 'str') → str | int | bool[ソース]

指定された質問と現在のゲームのスクリーンショットをエージェントに投げかけ、回答を取得します。

パラメータ:

  • question (str) -- 質問テキスト

  • answer_type (str, optional) -- 期待される回答の型（'str', 'int', 'bool'）。デフォルトは'str'。

戻り値:

エージェントからの回答

戻り値の型:

str|int|bool
